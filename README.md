## 📖 Overview

**Modern Gym Website** is a clean, professional, and fully responsive front-end template designed for gyms, fitness centers, and personal trainers. It combines bold visuals, smooth animations, and an intuitive layout to showcase services, trainers, pricing plans, and class schedules — helping visitors convert into members.

## ✨ Features

- 📱 **Fully Responsive** — Looks great on desktop, tablet, and mobile devices
- 🎨 **Modern UI/UX** — Clean layout with bold typography and smooth animations
- 🏋️ **Services & Classes** — Dedicated sections to showcase gym programs and class schedules
- 👥 **Trainer Profiles** — Highlight your team with photos and bios
- 💳 **Pricing Plans** — Clear membership tiers to drive conversions
- ⭐ **Testimonials** — Build trust with client reviews
- 📩 **Contact Section** — Easy-to-use contact form and location details
- ⚡ **Fast & Lightweight** — Built with clean, optimized code — no heavy frameworks required


## 🛠️ Built With

- **HTML5** — Semantic markup and structure
- **CSS3** — Custom styling, Flexbox/Grid layouts, animations
- **JavaScript** — Interactivity (navigation, sliders, form handling, etc.)

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No build tools required.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/saadullah990123/Modern-Gym-Website-.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd Modern-Gym-Website-
   ```

3. **Open the site**
   - Simply open `index.html` in your browser, **or**
   - Run a local server for the best experience:
     ```bash
     # Using Python
     python -m http.server 8000

     # Using Node.js (http-server)
     npx http-server
     ```
   - Then visit `http://localhost:8000`

## 🎨 Customization

Update the CSS variables (if defined) in your stylesheet to quickly rebrand the site:

```css
:root {
  --primary-color: #ff4d4d;   /* Main accent color */
  --secondary-color: #1a1a2e; /* Dark background */
  --text-color: #333;         /* Main text color */
}
```

Swap out images in the `assets/images/` folder and update text content directly in `index.html` to match your gym's branding.
